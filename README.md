# Медалі України · 2026

Публічна сторінка медальних підсумків виступів українських спортсменів на міжнародних змаганнях. На сторінці є пошук і фільтри за видом спорту та нозологією.

## Внесення результатів

Відповідальні заповнюють вкладку «Результати» в Google Sheets. Для багатовидового заходу використовуйте окремий рядок на вид спорту або залік і повторюйте офіційну назву заходу. Спільну медаль команди або заліку враховуйте один раз. У медальних колонках порожня клітинка означає відсутність даних, а нуль — підтверджену відсутність нагород відповідного кольору.

Скрипт публікує рядки з назвою заходу й хоча б одним заповненим медальним полем. Перед внесенням таких рядків звірте назви й цифри з протоколом.

## Публікація й оновлення

1. У Google Cloud увімкніть Google Sheets API. Надайте службовому акаунту право читати таблицю.
2. У GitHub відкрийте **Settings → Secrets and variables → Actions**. Додайте змінну `GOOGLE_SHEET_ID` з ідентифікатором таблиці й секрет `GOOGLE_SERVICE_ACCOUNT` із JSON-ключем службового акаунта.
3. У **Settings → Pages** виберіть **GitHub Actions** як джерело публікації.
4. У **Actions → Update medal results** запустіть **Run workflow** і перевірте опубліковані підсумки. Далі сценарій запускається щогодини за розкладом.

`export.py` формує публічний файл `results.json`, а `site/index.html` відображає його. Доступ до робочої таблиці мають відповідальні особи й службовий акаунт. У публічний експорт потрапляють назви заходів, види спорту, нозології, дати, місця проведення й медальні підсумки.
